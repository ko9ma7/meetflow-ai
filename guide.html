📖 MeetFlow AI 사용자 가이드 & 기능 설명서

노션(Notion)의 핵심 기능인 'AI 회의 노트 및 실시간 받아쓰기'를 웹 브라우저만으로 100% 무료 구현한 지능형 회의록 스튜디오입니다. 본 컴퓨터를 켜둘 필요 없이 언제 어디서나 바로 사용할 수 있습니다.

🌟 1. 서비스 개요 & 듀얼 아키텍처

MeetFlow AI는 "서버 호스팅 비용 0원, 24시간 가동, 강력한 방문자 PC 연산 활용"을 기본 철학으로 설계되었습니다. GitHub Pages 서버리스 모드와 로컬 오프라인 고성능 모드를 완벽하게 지원합니다.

☁️

GitHub Pages 서버리스 모드

내 컴퓨터를 꺼두어도 24시간 전 세계 어디서나 접속 가능. 방문자의 브라우저 로컬 저장소와 무료 AI API를 직결하여 서버 비용 0원 구현.

💻

로컬 PC 단독 실행 모드

인터넷 연결이 불안정한 환경이나 고보안 회의 시 로컬에서 node server.js를 실행하면 내장 Faster-Whisper GPU/CPU AI 엔진이 로컬 단독 전사를 수행.

🔒

강력한 프라이버시 & 무서버 저장

중앙 서버에 대화 내용이나 음성이 저장되지 않고 사용자의 컴퓨터 브라우저 내부(localStorage)에만 암호화 보관되므로 안전합니다.

AI 4단 요약 브라우저 내장 스마트 요약기 / Gemini Ollama / Gemini / Groq / OpenAI

🎙️ 2. 음성 녹음 & 실시간 전사 방법

우측 상단의 [✨ 받아쓰기 시작하기 ∨] 버튼을 누르면 3가지 방식의 음성 입력이 가능합니다:

1

🎙️ 마이크 실시간 회의 녹음 (대면 회의 / 발표)

회의실의 마이크나 노트북 내장 마이크를 통해 발화자의 목소리를 실시간으로 캡처합니다. 말하는 즉시 화면에 실시간 파형(Waveform)이 물결치며 문장이 끝나면 자동으로 타임스탬프([MM:SS])가 찍힌 말풍선이 생성됩니다.

2

🔊 유튜브 & PC 소리 녹음 (화상회의 Zoom/Meet, 유튜브 영상)

온라인 화상 회의(Google Meet, Zoom 웹 탭, Teams)나 유튜브 영상의 소리를 루프백으로 직접 녹음하여 전사합니다.

⚠️
[필독 핵심 팁] 크롬 화면 공유 창에서 [탭 오디오도 공유]를 꼭 켜주세요!
화면 공유 팝업이 뜰 때 [Chrome 탭]을 선택하고, 창 좌측 하단의 [탭 오디오도 공유] 체크박스를 켜주셔야 영상 소리가 시스템으로 입력됩니다.
3

📁 오디오 파일 업로드 (스마트폰 음성 메모, 녹음기 파일)

기존에 녹음해 둔 .mp3, .m4a, .wav, .webm 파일을 드래그 앤 드롭하거나 선택하여 전사할 수 있습니다. 60MB 이상의 대용량 오디오도 고속으로 처리됩니다.

👥 3. 스마트 화자 분리 & 실명 매핑 가이드

누가 어떤 말을 했는지 정확히 구분하는 것은 회의록의 핵심입니다. MeetFlow AI는 F0 피치(음높이), MFCC 음향 클러스터링, 대화 턴(질문/호응/답변) 분석을 결합하여 자동으로 화자를 구분합니다.

🏷️

원클릭 실명 매핑

화면 상단 화자 바에서 화자 1 ➔ 김대하 대표, 화자 2 ➔ 고호정 팀장으로 이름을 입력하면, 수백 개의 대화 말풍선과 향후 생성될 AI 요약문에 즉시 일괄 적용됩니다.

✨

[✨ AI 화자 분리 교정] 버튼

목소리가 겹치거나 한 사람에게 발언이 몰렸을 때 버튼을 한 번 클릭하면, 질문과 답변의 문맥 흐름을 AI가 다시 읽어 화자 경계를 즉시 자연스럽게 재분리합니다.

✂️

말풍선 수동 [✂️ 분할] & [🔗 병합]

각 대화 말풍선 우측 상단에 마우스를 올리면 나타나는 [✂️ 분할] 버튼으로 중간 문장을 나누거나, [🔗 병합] 버튼으로 바로 윗 발언과 하나로 합칠 수 있습니다.

✨ 4. 노션 AI 스타일 4단 자동 요약

전사가 완료된 후 상단의 [✨ AI 요약 생성] 버튼을 누르면, 노션(Notion)의 유료 AI 애드온과 완전히 동일한 4단계 구조화 문서가 자동으로 생성됩니다:

📌

1단계: 회의 개요 (Executive Summary)

회의의 핵심 목적과 결과를 2~3줄로 압축하여 바쁜 경영진도 10초 만에 파악할 수 있는 고밀도 브리핑을 제공합니다.

💡

2단계: 주요 논의 사항 (Key Discussions)

안건별로 논의된 세부 내용과 참석자들의 핵심 의견을 카테고리 태그([시스템 설계], [일정 검토])와 함께 일목요연하게 정리합니다.

🎯

3단계: 핵심 결정 사항 (Decisions Made)

회의 중 최종 합의되거나 확정된 정책, 규격, 일정 등을 명확하게 불릿 포인트로 제시합니다.

✅

4단계: 인터랙티브 액션 아이템 (Action Items)

누가(담당자), 언제까지(마감일), 무엇을 해야 하는지 체크리스트 형태로 추출됩니다. 웹 화면에서 직접 클릭하여 완료 체크([x])할 수 있습니다.

💡
맞춤형 5대 프롬프트 프리셋 탑재
회의 성격에 따라 일반 비즈니스, 전략/기획 검토, 개발/기술 스프린트, 영업/고객 미팅, 심층 인터뷰/HR 프리셋을 선택하여 최적화된 서식의 보고서를 얻을 수 있습니다.

📋 5. 노션 블록 복사 & 마크다운 내보내기

작성된 회의록은 노션(Notion)과의 호환성을 1순위로 고려하여 다양한 복사 및 저장 방식을 제공합니다:

📋

원클릭 노션으로 복사

AI 요약 탭 우측 상단의 [노션으로 복사] 버튼을 누른 후, 본인의 실제 Notion 빈 페이지에서 Ctrl + V를 누르면 노션 공식 콜아웃 상자, 체크박스, 볼드 서식이 그대로 완벽 렌더링됩니다.

💾

마크다운(.md) 파일 저장

상단 바의 [MD 저장] 버튼을 누르면 회의 메타데이터, 사전 안건, AI 요약, 전체 전사 녹취록이 모두 포함된 .md 파일이 즉시 다운로드됩니다.

👥

실명 적용 전사본 복사

카카오톡, 슬랙, 이메일에 전사본을 공유할 때, 타임스탬프와 매핑된 화자 이름(예: [10:15] 김대하 대표: 네 알겠습니다.)이 반영된 클린 텍스트가 복사됩니다.

🔑 6. 100% 무료 AI 연동 안내 (0원 비용 가이드)

MeetFlow AI는 API 키가 없어도 내장 브라우저 스마트 요약기로 즉시 사용 가능합니다. 하지만 1초 만에 완료되는 초고속 Whisper나 Google의 최신 모델을 사용하고 싶다면 아래의 평생 무료 API 키를 등록해 보세요:

⚡

Groq Whisper Large-v3 (추천: 1초 초고속 무료 전사)

1. console.groq.com/keys에 접속하여 구글 계정으로 1초 로그인합니다.
2. [Create API Key]를 눌러 무료 키를 복사합니다. (신용카드 등록 불필요, 100% 무료)
3. 스튜디오 좌측 하단 [⚙️ AI 모델 & STT 설정]에 키를 붙여넣고 저장합니다.

✨

Google Gemini 2.5 Flash (초정밀 무료 AI 회의 요약)

1. aistudio.google.com/apikey에 접속합니다.
2. [Create API key] 버튼을 눌러 무료 키를 생성합니다.
3. 스튜디오 설정창의 Gemini API 키 칸에 붙여넣습니다.

❓ 7. 자주 묻는 질문 (FAQ)

Q
Q. 내 컴퓨터를 꺼두어도 다른 사람들이 제 깃허브 페이지에 접속할 수 있나요?
A. 네! 깃허브 페이지(GitHub Pages)는 마이크로소프트 GitHub의 클라우드 서버에서 24시간 365일 무중단으로 동작하므로, 본인의 컴퓨터나 노트북을 꺼두셔도 전 세계 누구나 주소만 알면 언제든 접속하여 사용할 수 있습니다.
Q
Q. 스마트폰이나 태블릿(아이패드 등)에서도 동작하나요?
A. 네! 반응형 웹 인터페이스로 제작되어 모바일 화면에서도 자동으로 크기가 조절되며, 스마트폰 마이크 녹음 및 실시간 전사, AI 요약 확인이 완벽하게 지원됩니다.
Q
Q. 유튜브 소리가 녹음되지 않거나 전사가 안 돼요.
A. 크롬 화면 공유 창이 뜰 때 반드시 [Chrome 탭]을 선택하고, 창 하단의 [탭 오디오도 공유] 체크박스를 켜주셔야 합니다. 또한 유튜브 영상 플레이어 자체의 볼륨이 0(음소거)으로 되어 있지 않은지 확인해 주세요.
