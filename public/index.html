유튜브 영상 초고속 전사

유튜브 영상 주소(URL)를 입력하시면 영상을 실시간으로 끝까지 틀어둘 필요 없이, 백엔드에서 고속으로 음원을 추출하여 즉시 전사를 완료합니다.

영상을 틀어두지 않아도 20분 영상을 약 30초~1분 만에 화자 분리 및 전사합니다.
🔊

유튜브 & 컴퓨터 소리 실시간 녹음 안내

유튜브 영상, 줌(Zoom) 또는 컴퓨터에서 재생되는 오디오를 전사하려면 Chrome의 시스템 오디오 공유 기능을 사용합니다.

1
[화면/탭 공유 시작] 클릭 녹음 시작 시 브라우저에서 '화면 공유' 팝업이 나타납니다.
2
유튜브가 열려있는 탭 또는 전체 화면 선택 원하는 탭(예: YouTube 영상 탭)을 선택합니다.
3
⚠️ [시스템 오디오 공유] 체크박스 반드시 체크! 공유 팝업 좌측 하단의 '시스템 오디오 공유'(또는 '탭 오디오 공유') 스위치를 꼭 켜주셔야 소리가 전사 시스템으로 전송됩니다.

상용 웹서비스 배포 및 도커(Docker) 구축 가이드

MeetFlow AI는 사내 서버, 클라우드(AWS/GCP/Railway/Render) 또는 VPS에 즉시 상용 웹서비스로 배포할 수 있도록 완벽히 패키징되어 있습니다.

🐳 방법 1: 도커(Docker) 원클릭 배포

# 1. 도커 컨테이너 빌드 & 실행
docker-compose up -d --build

# 2. 브라우저에서 서비스 접속
http://your-server-ip:3000

컨테이너 내부에 Node.js 20 웹서버와 Faster-Whisper GPU/CPU AI 엔진이 모두 번들링되어 즉시 구동됩니다.

☁️ 방법 2: 클라우드 원클릭 호스팅 (Railway / VPS)

# GitHub 연동 후 바로 환경변수 설정
PORT=3000
WHISPER_MODEL=base
# 배포 완료 시 고유 HTTPS 도메인 자동 부여

Railway, Render, AWS LightSail 등에 Git 푸시만으로 자동 SSL(HTTPS) 인증서와 함께 배포됩니다.

TIP 서버에 NVIDIA GPU가 있는 경우 Dockerfile의 기본 이미지를 nvidia/cuda로 변경하면 전사 속도가 5배~10배 더욱 빨라집니다.

MeetFlow AI 공식 사용 설명서 & 기능 가이드

새 탭에서 보기 ↗

MeetFlow AI는 노션 AI 회의 노트를 웹 브라우저만으로 100% 무료 구동하는 지능형 회의록 스튜디오입니다. 본 컴퓨터를 켜둘 필요 없이 언제 어디서나 바로 사용할 수 있습니다.

🎙️ 1. 세 가지 음성 입력 방식

  • 마이크 실시간 녹음: 대면 회의, 발표 현장 발언을 실시간 타임스탬프와 함께 전사
  • 유튜브 & PC 소리 녹음: Zoom, Google Meet 화상회의 및 유튜브 영상 음원 다이렉트 전사 (화면 공유 창에서 [탭 오디오도 공유] 체크 필수)
  • 오디오 파일 업로드: MP3, M4A, WAV, WEBM 등 60MB+ 대용량 파일 즉시 전사

👥 2. 스마트 화자 분리 & 실명 매핑

  • 원클릭 실명 매핑: 화자 1 ➔ 김대하 대표 입력 시 수백 개 말풍선 및 요약문 일괄 치환
  • [✨ AI 교정]: 겹친 목소리나 한 사람에게 몰린 발언을 대화 턴/질문-답변 흐름으로 자동 재분리
  • 말풍선 [✂️ 분할] / [🔗 병합]: 문맥에 맞게 대화를 자유롭게 자르고 붙이기

✨ 3. 노션 AI 4단 자동 요약

  • 📌 회의 개요: 바쁜 경영진을 위한 2~3줄 고밀도 브리핑
  • 💡 주요 논의 사항: 카테고리 태그별 핵심 논의 내용 정리
  • 🎯 결정 사항: 최종 합의 및 확정된 정책/일정
  • ✅ 인터랙티브 액션 아이템: 담당자/마감일이 지정된 클릭 가능한 체크리스트
  • 💡 5대 맞춤 프리셋: 비즈니스, 기획, 개발 스프린트, 영업, 인터뷰

📋 4. 노션 연동 & 마크다운 내보내기

  • 노션으로 복사: Notion 페이지에서 Ctrl + V 시 공식 콜아웃, 체크리스트 블록으로 자동 렌더링
  • MD 저장: 메타데이터와 전사 녹취록이 포함된 .md 파일 즉시 다운로드
  • 실명 전사본 복사: 카톡/슬랙/이메일에 공유하기 좋은 정돈된 텍스트 복사
🔑 100% 무료 AI 연동 팁 (0원 비용):
• 실시간 마이크: 브라우저 내장 Web Speech API로 키 없이 평생 무료!
• Groq Whisper (1초 초고속): console.groq.com/keys에서 무료 키 생성 후 설정창에 등록하면 긴 녹음도 1초 만에 전사됩니다.
• Google Gemini: aistudio.google.com/apikey에서 무료 키 생성 시 초정밀 요약을 무료 제공합니다.
